# DHFM91.github.io

Splash page for everything public by David Feuling (DHF Media).

Live at **https://dhfm91.github.io**

## Adding or changing something

1. Open `index.html` and click the pencil (Edit) icon.
2. Find the block marked `EDIT EVERYTHING ON THIS PAGE RIGHT HERE`.
3. Copy any line that starts with `{ title:` and paste it into the section you want.
4. Change the title, tag, link and text. Leave `link: ""` if there's nothing to link to.
5. Click **Commit changes**. The live page updates in a minute or two.

Want a new section? Copy a whole `{ id: ..., title: ..., items: [ ... ] }` block.
